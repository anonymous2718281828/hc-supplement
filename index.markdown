# The Road not Taken -- Supplementary Website

This is the supplementary website for the paper "The Road not Taken: A Tale on Hidden Configurability".

On this web page, we will provide additional technical details and plots as mentioned in the paper.

## Finding Candidate Locations and AST Patterns.

More details on the AST patterns we defined to select candidate locations can be found on the "AST Patterns" subpage.

## Data Availability

We make our full measurement data available for individual verification of our results.
In addition, we make our set with candidate locations available for each subject system.

## Settings and Configuration Alternatives

More details on the defined settings, along with a mapping from setting ID and alternative ID to the respective values, can be found here.
