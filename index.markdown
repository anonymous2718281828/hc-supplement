# The Road not Taken -- Supplementary Website

This is the supplementary website for the paper "The Road not Taken: A Tale on Hidden Configurability".

On this web page, we will provide additional technical details and plots as mentioned in the paper.

## AST Patterns

More details on the AST patterns we defined to select candidate locations can be found on the "AST Patterns" subpage.

## Data Availability
This page contains details on our supplementary dataset.

## Execution Settings
This page contains details about the execution settings for each subject system.

## Configuration Alternatives
This page contains an overview of all configuration alternatives, including the patches used to create them and a mapping of configuration alternative ID to the corresponding value.

## Additional Plots
This subpage contains additional plots for each subject system.

## Reproducing
This page contains instructions on how to reproduce our results.

This includes a mere reproduction of tables and plots from the provided data, as well as a full reproduction of our measurement results, which requires the execution of our measurement framework.
