# Data Availability
We provide an artefact containing all measurements and data used in our study. The artefact is available at [Zenodo](https://doi.org/10.5281/zenodo.23033870).

The artefact contains the following files and folders:
- `data.csv`: A CSV file containing the aggregated measurements.
- `VaRA-TS-Data.zip`: A ZIP file containing the raw data and additional resources used in our study. To be used with the VaRA-TS. For more details, check the [Reproducing sub-page](/reproducing/).
- `patches/`: A folder containing the patches used to create configuration alternatives.
- `webpage/`: A folder containing the sources of this supplementary webpage. Can be run locally using Jekyll.
- `README.md`: A README file providing an overview of the artefact and instructions for usage.
